# เว็บไซต์ เกษสินีการม่าน · Kasinee Curtains (Golden Lux Curtain & Blinds)

เว็บแบบ static สร้างด้วย [Astro](https://astro.build) โฮสต์ได้ฟรีบน GitHub Pages / Netlify / Cloudflare Pages

## หน้าเว็บ
- `/` หน้าแรก: Hero → แนะนำตัว → สินค้าหลัก 3 อย่าง (กดแล้วเปิด pop-up) → ทำไมต้องเลือกเรา (ภาพหน้างาน + หมุด 3 จุด เทียบร้านทั่วไป/ของเรา) → 3 ผลงานเด่น → รีวิว → ติดต่อ
- `/portfolio/` เว็บผลงาน (สไตล์เว็บโรงแรม): ภาพเต็มจอ, ผลงานเด่น 3 งาน, ผลงานทั้งหมดพร้อมตัวกรองตามประเภทงานและชนิดม่าน, ปุ่มกลับหน้าหลัก
- `/portfolio/<id>/` หน้าเล่าเรื่องของแต่ละงาน (ภาพทั้งหมด, ข้อมูลงาน, ลิงก์โพสต์ Facebook)

## สองภาษา (TH / EN)
- ภาษาไทยอยู่ที่ `/` ภาษาอังกฤษอยู่ที่ `/en/` (เช่น `/en/portfolio/`) ปุ่ม TH/EN อยู่บน header ทุกหน้า
- เว็บจำภาษาที่เลือกไว้ในเบราว์เซอร์ คนที่เลือก EN ไว้ เปิดหน้าไทยจะถูกพาไปหน้าอังกฤษเอง
- ข้อความเนื้อหาทุกชิ้นเขียนเป็น `{ "th": "...", "en": "..." }` ส่วนปุ่ม/ป้าย และคำแปลประเภทงาน จังหวัด ประเภทบ้าน อยู่ใน `src/i18n/ui.json`

## แก้เนื้อหา (ไม่ต้องแตะโค้ด)
- `src/data/site.json` ข้อความหน้าแรก ชื่อร้าน สินค้า จุดเด่น รีวิว ช่องทางติดต่อ
  ข้อความใน `[วงเล็บเหลี่ยม]` = ยังรอข้อมูลจริง เว็บจะขึ้นกรอบเส้นประ "รอข้อมูล" ให้เห็น
- `src/data/portfolio.json` ข้อมูลผลงานทั้งหมด (1 รายการ = 1 งาน) แหล่งข้อมูลคือชีต portfolio-kaesiness.xlsx
- สี/ฟอนต์: แก้ค่าใน `:root` บนสุดของ `src/styles/global.css` ที่เดียว (ตอนนี้เป็นโทนเทาชั่วคราว)

## เพิ่มผลงานใหม่
1. ใส่รูปไว้ในโฟลเดอร์ เช่น `รูปผลงาน/<ชื่องาน dd-mm-yy>/`
2. เพิ่มรายการใน `src/data/portfolio.json` (ให้ `folder` ตรงกับชื่อโฟลเดอร์)
3. `npm run photos -- "รูปผลงาน"` (ย่อรูปลง `src/assets/portfolio/<id>/01.jpg, 02.jpg …`)
4. commit แล้ว push เว็บจะอัปเดตเอง

## รันบนเครื่อง
```
npm install
npm run dev      # http://localhost:4321
npm run build    # ได้เว็บใน dist/
```

## Deploy
`.github/workflows/deploy.yml` build และขึ้น GitHub Pages ทุกครั้งที่ push เข้า `main`
ต้องเปิดครั้งแรก: Settings → Pages → Source: **GitHub Actions**
